# 节日日历网站

一个纯静态、可本地运行的日历网站，展示中国法定节假日、调休上班日、常见中外节日，并标注每天是“休息”还是“上班”。

## 功能

- 月视图日历，支持 2024—2028 年切换
- 自动标注：
  - 休：法定节假日休息
  - 班：调休上班
  - 周：普通周末
- 点击日期查看农历、生肖、节日与休息状态
- 内置 2025 / 2026 年中国放假安排
- 支持春节、元宵、端午、中秋等农历节日

## 本地启动

### 方式一：双击启动

双击 `start.command`，会自动打开本地网站。

### 方式二：命令行启动

```bash
cd outputs/日历网站
python3 -m http.server 4173
```

然后浏览器访问：

http://localhost:4173

## 文件结构

- `index.html`：页面结构
- `assets/style.css`：样式
- `assets/app.js`：日历、农历、节日和放假逻辑
- `start.command`：macOS 双击启动脚本

## 部署

整个目录可以直接部署到任意静态托管服务，例如 GitHub Pages、Vercel、Netlify、Cloudflare Pages。
